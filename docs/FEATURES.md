# Інвентаризація можливостей T-Echo Plus

Стан перевірки вихідного коду: 2026-09-25. Назви пристроїв у публічних матеріалах: **Radio A** та **Radio B**.

Цей документ відрізняє реалізований код, параметри конфігурації та побажання, для яких реалізації ще немає. Наявність коду не означає перевірену дальність, точність датчика або сумісність з усіма версіями застосунків. Шляхи нижче відносні до кореня прошивки. Позначка «Реалізовано» описує код. Фізичні досліди попередніх персоналізованих збірок не є апаратною перевіркою нової публічної версії; її треба окремо пройти на двох раціях, зокрема після зміни ключа контакту.

## 3. Зв’язок, індикатори та відкладена доставка

Джерела: `src/modules/DeliveryQueueModule.cpp`, `test/custom_audit/test_delivery_payload.cpp`.

## 6. Безпека, оновлення й фізичні властивості

## 7. Публічні й локальні налаштування

- Radio A та Radio B — позначення тестових пристроїв; ID у прикладах синтетичні.
- `src/mesh/PairSettings.h` задає нульові ID за замовчуванням. Реальні ID записують до ігнорованого `src/mesh/PairSettings.local.h`. За нульових ID власна черга не перехоплює повідомлення; Peer/LED можуть стежити за favorite-контактом. Резервний favorite не стає адресатом власної черги.
- Емпіричні температурні поправки вимкнені за замовчуванням. `PAIR_ENABLE_THERMAL_EXPERIMENTAL=1` вмикає дослідну модель для налаштованих ID; це не підтвердження універсальної точності.
- LONG_FAST, регіон, timezone, звук/вібрація та інтервали — параметри конфігураційних прикладів. Вони починають діяти після застосування профілю; сам факт прошивання їх не встановлює.
- Приватні YAML/JSON, контактні QR, резервні копії, UART-логи та локальні бінарні збірки залишаються поза публікацією. YAML-експорт може містити ключі; бінарний файл — локальні ID. `.gitignore` не прибирає вже додані файли з історії Git.
- Статус перевірки конкретної версії записують у [TESTING.md](TESTING.md). Проходження host-тестів не замінює перевірки екрана, BLE-клієнтів і доставки через радіо.

Детальні правила очищення матеріалів: [PRIVACY.md](PRIVACY.md).
