# TH6: окремі гарячі поправки двох BME280

TH6 уточнює експериментальні профілі двох фізичних датчиків після виправлення полярності кнопки підсвітки H2. Виміри збережені в [calibration-th6.csv](../research/calibration-th6.csv). Це кімнатний дослід, а не заводське калібрування або гарантія точності надворі.

## Вхідні дані

Контрольний прилад за останнім повідомленням оператора: **26,9 °C / 41% RH**. Під час трихвилинного USB-читання контрольний прилад не зчитувався автоматично; сталість цих значень є припущенням. Усі 25 конверсій показали `frontlight=0`. Це стан керувального GPIO, а не оптичний вимір.

Для кожної рації взято середнє **останніх шести конверсій**, що охоплюють приблизно 75 с. Попередні точки цієї ж серії збережені, але не використані для підбору. Вологість вимірюється безпосередньо BME280, а MCU використовується для вибору емпіричної поправки.

| Величина | Radio A | Radio B |
|---|---:|---:|
| Сира температура BME, °C | 43,318333 | 41,556667 |
| Сира RH, % | 25,831667 | 20,878333 |
| Згладжена температура MCU, °C | 46,359667 | 43,129667 |
| Нова таблична поправка T, °C | 17,182994 | 14,656667 |
| Новий табличний RH gain | 0,583748 | 0,867299 |
| Попередній постійний T offset, °C | +0,764661 | 0 |
| Попередній множник RH датчика | 1,094644 | 1 |

Radio A раніше використовувала TH4 із верхньою точкою MCU 40,333333 °C. У новому вимірі було `range=1`: подальше зростання нагріву не збільшувало поправку. Її останній результат до TH6 — 30,22 °C / 57,72%; у Radio B — 26,08 °C / 42,54%. Це пояснює арифметичну недостатність таблиці A, але не встановлює всі фізичні причини нагріву корпусу.

## Як працюють поправки

```text
T = T_raw + sensor_T_offset − interpolated_heat(MCU_filtered)
M(T) = 17.625 × T / (243.04 + T)
RH = clamp(RH_raw × exp(M(T_raw) − M(T))
           × interpolated_RH_gain(MCU_filtered) × sensor_RH_gain, 0, 100)
```

Для підбору нового вузла:

```text
heat = mean(T_raw) + sensor_T_offset − T_reference
curve_RH_gain = RH_reference /
    (mean(RH_raw) × exp(M(mean(T_raw)) − M(T_reference)) × sensor_RH_gain)
```

Для A постійний offset уже врахований у значенні 17,182994. Його не можна вдруге віднімати як додаткове нагрівання. Так само табличний gain A не замінює її окремий множник 1,094644.

Перші вісім точок TH4 до MCU 40,333333 °C збережені для обох рацій. Вище:

- **A:** власна нова точка 46,359667 °C.
- **B:** власна нова точка 43,129667 °C і попередня TH5-точка 45,315 °C.

Між точками діє лінійна інтерполяція; за межами таблиці — крайня поправка без екстраполяції. Фільтр MCU 30 с, старт від фактичної температури MCU. Тиск не коригується. Контрольні T/RH не підставляються замість живих показів: нова сира конверсія змінює результат навіть у точці підбору.

## Межі досліду

- Дані для підбору не є незалежною валідацією. Наступний запис із рації перевіряє виконання формули; фізичну точність підтверджує лише одночасний контрольний вимір.
- Нових холодних вимірів у цій серії немає. Збереження попередніх холодних коефіцієнтів не доводить їхню точність у новій вологості.
- Абсолютна температура MCU залежить і від довкілля, і від навантаження. Та сама MCU під час заряджання, охолодження й перебування надворі може відповідати різним температурним градієнтам.
- При нових умовах потрібні пари `raw BME + filtered MCU + reference`; ручна температура CPU на екрані округлена.
- Період після виправлення підсвітки короткий; теплову рівновагу корпусу не встановлено.

Калібрування лишається вимкненим у публічній збірці за замовчуванням. Для власної пари потрібні локальні ID та свідоме ввімкнення `PAIR_ENABLE_THERMAL_EXPERIMENTAL`. Ці коефіцієнти не слід автоматично переносити на інші екземпляри.

## Перевірки

14 host-наборів пройшли. Тест теплової моделі перевіряє нижні незмінені діапазони, незалежні вузли A/B, зміну результату зі зміною сирого виміру, інтерполяцію, межі, перезапуск і фільтрацію. Збірка `t-echo-plus` також пройшла. Апаратні результати після встановлення записуються окремо нижче.

## Результат встановлення TH6

Обидві рації оновлені application-only DFU. Після перезапуску точна конфігурація, включно з ключами, збігається з резервною копією. У 90-секундній серії свіжих конверсій формула перевірена за сирими BME та згладженою MCU; керувальний GPIO підсвітки весь час вимкнений.

| Рація | Свіжі конверсії | Температура, °C | RH, % |
|---|---:|---:|---:|
| Radio A | 6 | 26.41–26.54 | 43.16–45.76 |
| Radio B | 7 | 26.28–26.68 | 41.66–43.17 |

[Контрольні записи](../research/calibration-th6-check.csv) отримані після підбору й не використані для зміни вузлів. Контрольні 26,9 °C / 41% перенесені з останнього повідомлення користувача, без повторного одночасного виміру; тому це перевірка прошивки й поточного наближення, а не незалежна метрологічна валідація. Окрема серія на батареї та при охолодженні ще потрібна.
