# Дані

[calibration-samples.csv](calibration-samples.csv) — дозволені числові поля 43 вибірок, без ID, координат, назв користувача й абсолютних часових позначок.

- Radio A / B — два різні екземпляри; коефіцієнти не слід переносити на довільні пристрої.
- `fit` — дані підбору; `same_run_holdout` — відкладена частина тих самих серій, а не незалежний лабораторний дослід.
- Dataset `post_install_live` — живі перевірки вже встановленої моделі; selection `not_used_for_fit`.
- Порожня комірка означає відсутність виміру/результату, не нуль.
- `reference_basis` та `filtered_mcu_basis` фіксують походження значень. Ручний контроль та наступний USB-зразок не гарантовано одночасні.

Назви полів, таблиця профілю, формули й обмеження описані в [CALIBRATION.md](../docs/CALIBRATION.md). Час/USB-історія приватних журналів сюди не перенесені, тому цей CSV сам по собі не відтворює весь безперервний тепловий процес.
