# Дані

[calibration-th5.csv](calibration-th5.csv) — одна нова сира вибірка Radio B з контрольними 26,4 °C / 38%. Це точка підбору продовженої кривої, не незалежна валідація. Розрахунок, проміжні коефіцієнти й обмеження наведені в [CALIBRATION-TH5.md](../docs/CALIBRATION-TH5.md).

[calibration-th5-check.csv](calibration-th5-check.csv) — чотири свіжі вибірки після встановлення TH5. Не використані для підбору; контрольні значення перенесені з останнього повідомлення, а не виміряні повторно. Призначення — перевірити застосування таблиці до живих сирих даних.

[calibration-samples.csv](calibration-samples.csv) — дозволені числові поля 43 вибірок, без ID, координат, назв користувача й абсолютних часових позначок.

- Radio A / B — два різні екземпляри; коефіцієнти не слід переносити на довільні пристрої.
- `fit` — дані підбору; `same_run_holdout` — відкладена частина тих самих серій, а не незалежний лабораторний дослід.
- Dataset `post_install_live` — живі перевірки вже встановленої моделі; selection `not_used_for_fit`.
- Порожня комірка означає відсутність виміру/результату, не нуль.
- `reference_basis` та `filtered_mcu_basis` фіксують походження значень. Ручний контроль та наступний USB-зразок не гарантовано одночасні.

Назви полів, таблиця профілю, формули й обмеження описані в [CALIBRATION.md](../docs/CALIBRATION.md). Час/USB-історія приватних журналів сюди не перенесені, тому цей CSV сам по собі не відтворює весь безперервний тепловий процес.

[display-cooling-observations.csv](display-cooling-observations.csv) — окремі чотири покази двох рацій на двох фотографіях з інтервалом приблизно 13 хвилин. Це округлені скориговані цифри екранів і приблизно прочитана температура MCU; сирих BME та згладжених MCU немає. Вони не додані до набору сирих калібрувальних вибірок і не використані для fitting. Зображення, особисті назви й абсолютний час не публікуються.
